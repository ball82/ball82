## 🎯 Projekte

### 📋 Join – Kanban Task Management
Webbasiertes Task-Management-Tool mit Kanban-Board, Drag-&-Drop zwischen Spalten, Subtasks, Kontaktverwaltung und Dashboard. Benutzerverwaltung über Firebase Authentication, Daten in Echtzeit über die Firebase Realtime Database. Modularer Aufbau aus rund 30 JavaScript-Modulen.

**Tech Stack:** JavaScript (ES6+) · HTML5 · CSS3 · Firebase (Auth & Realtime Database)
🔗 [Live Demo](https://www.bajo-dev.ch/sub/join/) · [Repository](https://github.com/ball82/Join)

---

### 🍕 bestellApp (ItaFood) – Online-Bestellsystem
Bestell-App für einen Lieferdienst mit Speisekarte (Pizza, Pasta, Desserts, Getränke), Warenkorb mit Mengenänderung, dynamischer Preisberechnung inkl. Liefergebühr-Logik (ab 25 CHF versandkostenfrei) und Bestellabschluss. Responsive umgesetzt mit Bootstrap.

**Tech Stack:** JavaScript (OOP) · HTML5 · CSS3 · Bootstrap 5
🔗 [Live Demo](https://www.bajo-dev.ch/sub/bestellapp/) · [Repository](https://github.com/ball82/bestellApp)

---

### 🎮 El Pollo Loco – Jump-and-Run-Spiel
2D-Jump-and-Run-Spiel mit eigener Spiellogik: Gegner- und Kollisionssystem, Level-Mechaniken und Eventsteuerung. Umgesetzt mit HTML Canvas und objektorientiertem JavaScript.

**Tech Stack:** JavaScript (OOP) · HTML Canvas · CSS
🔗 [Live Demo](https://www.bajo-dev.ch/sub/el_pollo_loco/) · [Repository](https://github.com/ball82/El-Pollo-Loco)
